MEDex 모바일 (웹앱) 설치 안내
==============================

PC의 MEDex와 같은 Google Drive 데이터(MEDex_notes.json)를 폰 브라우저에서 읽고 수정합니다.
(굵게/밑줄/크기/색/체크박스/암호 인덱스 포함. 암호는 PC와 같은 방식으로 폰 안에서만 풀고 다시 잠급니다.)

[1] Google Cloud 콘솔에서 '웹' OAuth 클라이언트 만들기  (PC 앱을 만들 때 쓴 프로젝트 그대로 사용)
  1. https://console.cloud.google.com → 같은 프로젝트 선택 → API 및 서비스 → 사용자 인증 정보
  2. '사용자 인증 정보 만들기' → 'OAuth 클라이언트 ID' → 애플리케이션 유형: '웹 애플리케이션'
  3. '승인된 JavaScript 원본'에  https://내깃허브아이디.github.io  추가  (경로 /medex 는 쓰지 않음, 슬래시 없이)
  4. 만들어진 '클라이언트 ID'를 복사 (….apps.googleusercontent.com)
  ※ OAuth 동의 화면이 '테스트' 상태면, 로그인할 Google 계정이 '테스트 사용자'에 들어 있어야 합니다. (PC 앱과 동일)

[2] config.js 고치기
  이 폴더의 config.js 에서 "여기에_웹_클라이언트_ID를_붙여넣으세요.apps.googleusercontent.com" 부분을 위 클라이언트 ID로 바꿉니다.

[3] GitHub Pages에 올리기
  1. GitHub에서 새 저장소(예: medex) 만들기 (Public)
  2. 이 mobile 폴더 안의 파일들 (index.html, config.js, sw.js, manifest.webmanifest, icon-192.png, icon-512.png) 을 저장소 맨 위에 올리기
  3. 저장소 Settings → Pages → Branch: main / (root) → Save
  4. 잠시 뒤  https://내깃허브아이디.github.io/medex/  로 접속됩니다.
     (1-3 에 등록하는 원본은 경로를 뺀  https://내깃허브아이디.github.io  입니다)
  ※ config.js에는 비밀값이 아니라 공개용 '클라이언트 ID'만 들어갑니다. credentials.json(클라이언트 보안 비밀)은 절대 올리지 마세요.

[4] 폰에서 사용
  - 폰 브라우저(Chrome/Safari)로 위 주소를 열고 'Google 계정으로 로그인' (PC와 같은 계정)
  - 브라우저 메뉴의 '홈 화면에 추가'를 하면 앱처럼 쓸 수 있습니다.

사용법 (일반 메모 앱처럼)
  - 첫 화면은 인덱스 목록입니다. 인덱스를 눌러야 그 메모가 열리고, ‹ 로 목록에 돌아옵니다. (폰의 뒤로 가기 버튼도 동작)
  - 목록 각 줄 오른쪽 ⋯ (또는 편집 화면의 ⋯): 즐겨찾기(최대 2개), 이름 변경, 색 변경,
    암호 설정/변경/초기화(영문 1자 + 숫자 4자리, 대/소문자 구별), 삭제(휴지통).
  - 편집 도구: 가(작게/기본/크게), B, U, 글자 색, □ 체크박스(눌러서 체크/해제), ★ 즐겨찾는 기호, 되돌리기/다시 실행.
  - ⚙ 설정: 자동 저장, 체크 시 선 긋기, PC 화면 불투명도, 인덱스 제목 표시 방향, 즐겨찾는 기호 등록/순서/삭제, 휴지통(복원/완전 삭제/비우기), 로그아웃.
  - 모든 설정과 데이터는 PC와 같은 Google Drive 파일에 저장되어 PC와 그대로 동기화됩니다.
  - 3초 쉬면 자동 저장 (설정에서 자동 저장을 끄면 '저장' 버튼으로만 저장).

주의
  - 저장할 때마다 Drive의 최신본을 받아 '이 인덱스만' 고쳐 올립니다. (다른 기기에서 고친 다른 인덱스는 보존)
  - PC의 MEDex는 30초마다(저장할 내용이 없을 때) Google의 더 최신 메모를 자동으로 불러옵니다. (v1.0.4 이상)
  - 같은 인덱스를 PC와 폰에서 동시에 고치면 나중에 저장한 쪽이 이깁니다.
  - 폰 화면에서는 체크박스가 글자(☐/☑)로 보입니다. 저장 형식은 PC와 같습니다.
